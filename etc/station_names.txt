# 満点地震計の拠点名の読み替え(外部に発表するときの名前。表示のときだけ。オプション)
#   メイン画面の「拠点名を発表用の名前で表示する」を入れると、図・画面に出す拠点名をここに書いた名前に読み替える
#   (既定は外してあり、今までどおり内部名を出す。入れたかどうかはユーザーの設定の settings.json に覚えておく)
#   内部名(SAC・チャンネル表の観測点コード)は変わらないので、保存した到着時刻(picks)・キャッシュ・
#   CSV の列名・ファイル名・ログの文は内部名のまま
#   自分用に変えるときは、このファイルをユーザーの設定の etc に写して直す(同じ名前があればそちらを使う)
#     Mac ... ~/Library/Application Support/UsuMantenViewer/etc / Windows ... %APPDATA%\UsuMantenViewer\etc
#
# 1行に1拠点: 内部名  正式名  [略称]  # 説明
#   正式名 ... 図のタイトル・拠点の選択欄・結果の文などに使う
#   略称   ... 波形の縦軸・配置図の注記など、狭い所に使う(省くと正式名)
#   名前には空白と「.」を使えない(「拠点名.成分」の形で使うため)
#   書いていない拠点(Mimatsu など)は、内部名のまま出す
