# 有珠満点地震計 波形ビューワ（UsuMantenViewer）

有珠山周辺に設置した満点地震計の観測データ（WIN形式）を表示・解析するアプリです。日ごとのZIPファイルから必要な期間のデータを取り出し、SAC形式に変換して、波形の表示や震度の推定、P波・S波の到着時刻の検出を行います。

- バージョン: 3.3.0
- 動作環境: Windows 10 / 11、Mac（Apple Silicon）
- 使用ライブラリ: ObsPy、Matplotlib、Tkinter、Google API（Googleドライブからのダウンロード）

---

## 主な機能

### 指定期間の波形表示
- 開始・終了日時（`YYYYMMDDHHmm`）を指定して、全拠点・全成分（U/N/E）の波形を表示します。縦軸は速度（cm/s）です。
- 4拠点のときは拠点ごとの2x2表示になり、ボタンで縦に並べる表示と切り替えられます。
- 表示した期間は履歴に残り、あとから呼び出せます。

> **震度とマグニチュードは推計です。** 満点地震計の物理的な特性のうち、波形を速度（m/s）に直す値で分かっているのは、ロガー（EDR-X7000）の資料にある A/D 変換の量子化ステップ幅（0.644 μV/LSB）だけです。地震計の感度（64 V/(m/s)）とゲイン（0 dB）、固有周期（1 秒）は資料が無く、近くの防災科研の観測点（N.USSV）の振幅に近くなるように決めた推定値です（`etc/manten_ch.tbl`）。そのため、振幅をもとにする震度とマグニチュードは推計で、地震計の実際の値が分かれば変わることがあります。なお、気象庁の震度・震源リストの M とは、おおむね合うことを確かめています。

### 震度推定
- 選んだ拠点の3成分から、気象庁の方法で計測震度と震度階級を計算します。
- 計算の途中経過（加速度波形、フィルター後の波形、3成分合成加速度など）もグラフで表示します。
- 地震計の感度などが推定値のため、震度は推計です（上の注意を参照）。

### P波・S波検出
- STA/LTA 法で P波・S波の到着時刻を検出し、S-P時間と大森公式から震源までの距離を推定します。
- スライダーとプリセットでパラメータを調整でき、設定は次回に引き継がれます。
- 気象庁の震源リスト（`jma_hypocenter.py` で取得済みのもの）に、検出した P波に合う地震があれば、震央地名・発生時刻・M・深さ・震央距離・方位と、P波・S波の到達見込み（波形に点線でも表示）を結果の欄に表示します。

### 震源推定
- 上下動から P波、水平動から S波の到着時刻を検出し、震源の位置（緯度・経度・海面からの深さ）と発生時刻を推定します。
  - P波は STA/LTA で検出したあと、その前後を AIC 法で決め直します。S波は、P波から「S波を探す範囲」の秒数までの水平動のエネルギーに AIC 法を使います。
  - 震源は P波・S波の到着時刻を合わせ、均質な速度構造（P波の速度と vp/vs はスライダーで変更。既定は有珠山周辺の浅い地震に合わせた 3.0 km/s・1.73）で求めます。拠点の高度も考えます。
  - Bamba は雑音が多く S波の検出がずれやすいため、最初は S波を計算に使いません（右クリックで使えます）。
  - 深さは、残差がほぼ同じ（最小の残差の3割増し、または 0.01秒増しまで）になる範囲も出します（例: 「1.7 km（1.0〜2.4 km）」）。浅い方の端まで残差がほぼ同じときは、「浅い（0.6 km より浅い）」のように表示し、断面図では海面（0 km）に描きます（P波だけで求めたときなど）。
  - 残差が大きいとき（0.15秒超）は、遠い地震か検出のずれとして注意を表示し、配置図の震央を白抜きにします。
  - 震源が決まったときは、推定マグニチュード（M）も表示します（`magnitude.py`）。満点の拠点ごとに、上下動（2〜20 Hz）の速度の最大振幅と震源距離から渡辺の式（0.85 M − 2.50 = log A + 1.73 log r）で M を求め、拠点ごとの補正（Bamba 0.93・Hokudai 1.11・Mimatsu 1.44・Nizaemn 0.93）を引いた値の中央値です。補正は、震源距離 200 km までの震源リストの地震56件で、渡辺の式の M と気象庁の M の差から決めました（補正後の差は平均ほぼ0、ばらつき ±0.45 程度）。揺れの最大が発生時刻より前の雑音の3倍に届かない拠点は使いません。ほかの機関の観測点は使いません。残差が大きい（0.15秒超）近い地震の震源では求めません（遠い地震を近くに決めてしまい、距離が小さすぎて M が大きく外れるため）。遠い地震として震央を推定できたときは、大森公式の距離を震源距離として、最初の P波から表示範囲の終わりまでの最大振幅で求めます（S波の最大が範囲に入るように表示してください）。震源距離が 200 km を超えるとき、または合う震源リストの地震が 200 km より遠いときは求めません（渡辺の式は 200 km くらいまでの地震向けで、補正もその範囲で決めたため。2026/8/23 22:45 の浦河沖 M6.0（震源距離 約190 km）は、遠い地震として M 5.5 になります）。地震計の感度などが推定値のため、M は推計です（上の注意を参照）。
- 拠点の間隔が数kmしかないため、遠い地震は P波・S波の到着時刻でも位置が決まりません。その場合（探索範囲外や残差が大きいとき）は、P波から求めた到来方向と、S-P時間から大森公式（距離 = k × S-P時間。k はスライダーで変更、既定 8.0 km/s）で求めた距離から震央を推定します。遠い地震では「S波を探す範囲」を S-P時間より長く（例: 震央距離 200 km 前後なら30秒）してください。
- 3拠点以上の波形があれば開けます（指定期間の波形表示の「震源推定」ボタン）。グラフの下に線の意味を表示します。右下の結果の欄は、見出し（◆）・注意（※、赤）・気象庁の震源リスト（青緑）を色分けしています。
- 「波形」のボタンで上下動と水平動の表示を切り替えます。到着時刻は波形のクリックで手直しでき（上下動では P波、水平動では S波。Shift+クリックでその拠点だけ自動検出に戻す）、右クリックでその拠点（水平動では、その拠点の S波）を計算から外せます。波形は 2-20Hz のフィルターをかけて表示します（切り替え可）。
- 「到着時刻を保存」で、P波・S波の到着時刻（手で直したもの・自動のもの）、計算から外した拠点、パラメータを `output/picks/<最初の P波の日時>.json` に保存します。同じ地震の範囲を開いたときは、この画面・P波・S波検出の画面（その拠点の保存した到着時刻を橙・紫の実線で表示）・地震の候補の震源（画面とバッチ処理）のどれでも、保存した到着時刻を使って再現します（右上に読み込んだファイル名を表示）。「自動検出に戻す」で自動の検出に戻せます。
- 気象庁の震源リスト（取得済みのもの）に、最初の P波に合う地震があれば、その情報と到達見込み（波形に点線）を結果の欄に表示し、配置図に震央（範囲外なら方位の矢印）を示します。推定した震央との距離、または到来方向との差も表示します。
- 拠点の配置図の背景に、地理院タイル（標準地図・色別標高図）を表示します（インターネット接続が必要。取得したタイルはユーザーのキャッシュフォルダ `UsuMantenViewer/map_tiles` に保存し、2回目からはそれを使います）。拠点の位置は `etc/manten_ch.tbl` から読み込みます。
- ほかの機関の観測点（気象庁・防災科研）の波形があれば、拠点に加えます（TODO 21 の検証用。今は気象庁の有珠南山麓 V.USUA・北屏風山 V.KBBY と、防災科研の有珠山大平 N.USOV を、`USUA`・`KBBY`・`USOV` として加えます）。
  - 観測点は `etc/external_stations.txt` に書きます（画面で使う名前・WIN の観測点コード・位置）。
  - 波形は、防災科研の「基盤的火山観測網（V-net）」のページなどからダウンロードした ZIP（例: `03_02_07_202607081119_6.zip`。WIN32 形式の `.cnt` とチャンネル表 `.euc.ch` が入ったもの）を、`v-net` フォルダにそのまま置きます（防災科研・気象庁のデータで再配布できないため、Git の管理外）。表示している期間を含む ZIP があれば、使う観測点の上下動・水平動だけを SAC に変換し（1分ごとのファイルをつないでから `win2sac_32` で変換）、`output/vnet` に保存して再利用します。ZIP の一覧と変換済みの SAC は、メンテナンス画面で確かめられます。
  - 加えた観測点も、右クリックで計算から外せます。外したときと比べて、震源がどう変わるかを確かめられます。

### 1時間スタック波形
- 1時間分の波形を1分ごとに60段に並べて表示します。
- 前後の1時間への移動、拠点・成分の切り替え、ホイールでのズーム、ドラッグでの横移動ができます。
- 波形を右クリックすると、その分から 1〜30分間の全拠点の波形表示（指定期間の波形表示）を開けます。
- 成分ボタンの右の「地震」「列車」ボタンで、その1時間に重ねて表示できます（オンにした状態は、時間・拠点を変えても続きます）。色の説明は「凡例」ボタンで出ます。バッチ処理の画像にも、`--quakes`・`--trains` で重ねられます。
  - 地震: 地震の候補（3拠点以上が同時に雑音の20倍を超えた揺れ）を帯で示します。気象庁の震源リストと照合できたものは紫、照合できないもの（未知の地震かもしれないもの）は桃色です。震源リストの地震の P波・S波の到達見込み（表示中の拠点）は縦線で示します。地震の候補を探す処理（`--detect-quakes`）で保存した `output/quake_rms` と、取得済みの震源リストを使います。`output/quake_rms` が無い日は候補の帯を出せないので、図の左下にその旨を表示します（メンテナンス画面の「地震の候補を探す」で作れます）。
  - 列車（Bamba だけ）: 洞爺駅の時刻表（`etc/train_timetable.csv`。JR の時刻表から作るもので再配布できないため、Git の管理外）と対応した列車の揺れ・貨物列車の候補・その他の揺れを、`train_day_plot.py` の画像と同じ帯と ▼ で示します。雑音の基準と遅れを見込むため、前後の1時間も読み込みます。
- 図の下の操作エリア:
  - 「画像を保存」: 表示中の1時間を、バッチ処理と同じ形の画像（PNG・PDF・SVG）で保存します。オンにしている重ね表示（下に色の説明を入れる）と横軸の拡大は今の表示のままで、上のボタンは入りません。
  - 「v-net の連続波形画像」: 選んだ観測点の、表示中の1時間・成分（U・N・E）の連続波形画像（防災科研のページ。1段が1分）をブラウザで開きます。満点の拠点では雑音との差が小さい揺れを、ほかの機関の観測点でざっと確かめるのに使います。選べるのは有珠山の地震計のある観測点で、防災科研の USSV（壮瞥）・USOV（大平。地中）・USIV（泉の沢）と、気象庁の USSW（昭和新山南麓）・USUA（南山麓）・KBBY（北屏風山）・ATIK（虻田泉北）です（気象庁の USHU（東有珠大平通）は傾斜計だけなので入れていません）。選んだ観測点は、次に開く画面でも使います。

### キーボード操作（ショートカット）
Mac は ⌘（Command）キー、Windows は Ctrl キーと組み合わせます（表の ⌘ は Windows では Ctrl）。ボタンの文字にも添えています。

| 画面 | キー | 操作 |
|---|---|---|
| メイン画面 | ⌘↩（Ctrl+Enter） | 抽出・変換・プロット実行（日時の欄に入力したまま押せます） |
| | ⌘O | 候補の一覧(CSV)を選んで震源を表示 |
| 指定期間の波形表示 | ⌘I | 震度推定（選んだ拠点） |
| | ⌘P | P波・S波検出（選んだ拠点） |
| | ⌘L | 震源推定 |
| | ⌘W | 閉じる |
| 震度推定・P波・S波検出 | ⌘W | 閉じる（Matplotlib の標準の操作。閉じると元の波形表示に戻ります） |
| 震源推定 | U・H | 波形の表示を上下動（P波）・水平動（S波）に切り替え（修飾キーなし） |
| | ⌘S | 到着時刻を保存（地震の候補の震源から開いたときは「保存して一覧に反映」） |
| | ⌘W | 閉じる（閉じると、開いた元の画面に戻ります） |
| 1時間スタック波形 | U・N・E | 成分の切り替え（修飾キーなし） |
| | ←・→ | 1時間前・後（修飾キーなし） |
| | ⌘E・⌘T | 「地震」「列車」の重ね表示の切り替え |
| | ⌘S | 画像を保存 |
| | ⌘G | v-net の連続波形画像を開く |
| | ⌘W | 閉じる（Matplotlib の標準の操作） |
| 地震の候補の震源 | ↩（Enter） | 選んだ候補の震源推定の画面を開く |

修飾キーなしのキー（U・N・E など）は、文字を入力する欄を選んでいるときは効きません。震源推定の画面では、Matplotlib の標準のキー操作（s で保存、h で表示を戻す など）は使わず、上の割り当てにしています。

### データの取得とキャッシュ
- 手元の `daily_zips` に無い日付のZIPファイルは、Googleドライブから自動でダウンロードします（中止もできます）。
- 取り出したWINファイルや変換したSACファイルは `output` にキャッシュし、同じ期間は再利用します。
- 「出力データキャッシュ整理」で、結合前のWINファイル・結合後のWINファイル・SACファイルを種類ごとに削除できます（`output/picks`（保存した到着時刻）と、`picks` で始まるそのバックアップ、`output/quake_rms`、`output/quake_features`、`output/vnet` は削除しません）。

### メンテナンス画面
メイン画面の「メンテナンス…」ボタンで開きます。ボタンの横には、震源リストを取得済みの最後の日を表示します（取得していない日があれば赤字）。
- 気象庁の震源リスト: 取得済みの期間と、観測の最初の日から昨日までで取得していない日を表示します。「不足分を取得」は `jma_hypocenter.py` を引数なしで実行したときと同じで、取得済みの最後の日も、暫定値の更新を確かめるため取り直します。期間（YYYYMMDD）を入れて「取り直す」と、取得済みの日も取り直します。前回との違いは実行ログに表示します。1日ごとに2秒あけて取得し、途中で中止もできます。
- 地震の候補の検出: `--detect-quakes` と同じ処理を画面から実行します。揺れの大きさ（RMS）を保存済みの期間と、daily_zips にあってまだ計算していない日を表示します。期間（YYYYMMDD、空けると daily_zips の最初の日から最後の日まで）を入れて「地震の候補を探す」を押すと、まだの日だけ RMS を計算し、候補の一覧などを `batch_plots/quakes` に保存します。確認用の画像・PDF の保存、候補の履歴への追加、外部の観測点で確かめるためにダウンロードする60分の一覧の作成も選べます。別スレッドで実行するので、途中で中止できます（手元の daily_zips の ZIP だけを使い、Googleドライブからはダウンロードしません）。
- キャッシュ: 「出力データキャッシュ整理」と「波形Zipファイル整理」です。
- ほかの機関の観測点: 設定の観測点（`etc/external_stations.txt`）と、`v-net` フォルダの ZIP ごとの開始時刻・長さ・大きさ・変換済みの観測点を一覧にします。まだ変換していない ZIP の変換、変換済みの SAC（`output/vnet`）の削除（観測点の設定を変えたときなど）、`v-net` フォルダと設定ファイルを開くこともできます。

### バッチ処理
- 画面を出さずに、指定したチャンネル・期間の1時間スタック波形の画像を一括で保存します（`batch_plots`）。

### 地震の候補の震源（画面・バッチ処理）
- メイン画面の「候補の一覧(CSV)を選んで震源を表示」で一覧の CSV を選ぶと、同じ方法で震源を求め、結果の表と震央の地図・東西と南北の断面図を並べた画面を開きます。表の行を選ぶと地図と断面図に印を付け、ダブルクリック（または「震源推定を開く」）でその候補の震源推定の画面を開いて、到着時刻を手で直して確かめられます。震源推定の画面で「保存して一覧に反映」を押すと、到着時刻を `output/picks` に保存し、そこから求め直した震源で表の行（「手直し」の列に○）と地図・断面図を更新します。「自動に戻す」で、選んだ候補の保存した到着時刻を消して自動の検出に戻します。「一覧と図を保存」でバッチ処理と同じ CSV と画像を保存します（保存せずに閉じようとすると確かめます）。
- `--locate-quakes` に地震の候補の一覧（`--detect-quakes` の `quake_candidates_*.csv`）を渡すと、候補ごとに震源推定の画面と同じ方法・既定値で震源を求めます。一覧に「候補」の列があれば、その列に何か書いてある行だけを使います（Excel で印を付けて CSV に保存したもの。UTF-8 と Shift_JIS のどちらでも読めます）。
  - P波は短い STA/LTA で検出して AIC 法で決め直し、S波は P波のあとの水平動から AIC 法で検出します。震源リストと対応した遠い地震は、その S-P時間の見込みに合わせて S波を探す範囲を広げます。
  - 判定は「近い地震」（P波・S波から震源が決まった）、「近い地震(残差大)」（S-P時間は短いが残差が 0.15秒を超える。到着時刻の検出がずれていることが多いので、震源推定の画面で確かめる）、「遠い地震」（到来方向と S-P時間から震央を推定）、「決まらない」（到着時刻が足りない）です。
  - 震源推定の画面で保存した到着時刻（`output/picks`）がある候補は、自動の検出の代わりにそれ（とそのときの速度・k）を使います。
    保存した到着時刻にほかの機関の観測点（`etc/external_stations.txt`）があれば、その観測点も使います（自動の検出には使いません）。CSV にその観測点の到着時刻の列を足し、地図・断面図に灰色の三角で描きます。
  - 遠い地震の自動の推定は、距離は震源リストとおおむね合いますが（中央値で約35 km 短い）、到来方向は P波の自動検出のずれで大きく外れることがあります。
- 結果は `batch_plots/quakes/locate` に保存します。
  - `<一覧の名前>_locations.csv` … 候補ごとの判定、手直し（保存した到着時刻のファイル名）、拠点ごとの P波（最初の拠点からの秒）・S-P時間、震源（緯度・経度・深さ・残差・発生時刻）、到来方向、遠い地震の距離、震源リストの震源と、その震央との距離、山頂からの距離
  - `<一覧の名前>_locations.png`・`.svg` … 近い地震の震央の地図（地理院タイル）と、東西・南北の断面図（SVG は拡大しても粗くならない。ほかの機関の観測点の名前は、東西断面では重ならないように欄外に引き出して書く）
  - `<一覧の名前>_<開始日時>.png` … 確認用の画像（`--images`。拠点ごとに上下動と水平動を並べ、P波・S波の位置と震源リストからの到達見込みを示したもの）

例: 地震の候補の一覧から震源を求め、確認用の画像も保存する

```bash
python3 scripts/UsuMantenViewer.py --locate-quakes batch_plots/quakes/quake_candidates_20250708_20260826.csv --images
```

### 地震の候補の検出と震源リストとの照合（バッチ処理）
- 画面を出さずに、指定した期間（省略すると `daily_zips` の全期間）から地震らしい揺れを探します。上下動を 2〜20 Hz のフィルターに通して10秒ごとの RMS にし、3拠点以上で同時に雑音（前後30分の中央値）の20倍を超えたところを地震の候補とします（基準は `train_day_plot.py` で決めたもの）。データのある拠点が3拠点より少ない時間は調べません。
- 有珠山の直下の小さな地震を拾うため、山頂に近い Hokudai が雑音の40倍以上で、ほかの2拠点以上が4倍以上のときも候補にします（Hokudai の例外。一覧の「検出の基準」が `Hokudai` のもの）。
- 候補の揺れの始まりと終わりは、拠点の倍率の中央値が3倍を下回るところまでとします（10秒単位）。
- 気象庁の震源リスト（`jma_hypocenter.py` で取得したもの）の地震ごとに、拠点の中心までの距離と P波・S波の到達見込み（ObsPy の TauP、速度構造 iasp91）を計算し、揺れの始まりが合う地震を候補に対応させます。計算した走時はユーザーのキャッシュフォルダ `UsuMantenViewer/travel_times_iasp91.json` に保存し、2回目からは新しく増えた地震の分だけを計算します（全期間で約2分 → 約5秒）。候補ごとの波形の解析結果（P波の到着時刻・周波数など）も `output/quake_features` に保存し、始まりと終わりが同じ候補は、次からは波形を読まずにそれを使います。見込みの振幅（坪井の式に、遠いほど高い周波数の揺れが弱まる分を加えた目安）が大きいのに候補が無い地震は「見逃し?」として別の一覧にします。
- 候補ごとに波形を解析し（P波の検出拠点数、P→最大振幅、卓越周波数、見かけの速度、到来方向、近い地震としての震源。`quake_features.py`）、震源リストに無い候補には「有珠山の地震らしさ」（高・中・低）を付けます。P波を3拠点以上で検出でき、P→最大振幅が3.5秒以下、見かけの速度が2.5 km/s 以上、揺れが60秒以下ならば「高」、3つの条件のうち2つなら「中」です。震源リストで有珠山の地震とされたもの（山頂から10km以内・深さ10km以内）は「確定(震源リスト)」とします。
- 昼間は雑音が夜の数倍〜20倍あり、短い小さな地震は拾えないことがあります（10秒ごとの RMS では、数秒の揺れが薄まるため）。
- 外部の観測点で確かめる60分の一覧（`--vnet-list`、メンテナンス画面のチェック。`quake_loose.py`）: 満点の4拠点だけでは基準に届かない小さな地震を、気象庁・防災科研の観測点（USUA・KBBY・USOV）の波形で確かめるためのものです。外部の観測点の連続波形は防災科研のページから手で60分ずつダウンロードするしかないので、次のように数を絞ります。
  - 基準をゆるめた候補: 3拠点が雑音の10倍を超え、どこかの拠点が20倍以上のもの、または Hokudai が40倍以上で、ほかの1拠点が20倍以上のもの。今の候補と重なるものは除きます（2026/6/1〜7/31 で試し、外部の観測点で地震と確かめた 6/13 22:35・6/23 12:58・7/8 11:20 をすべて拾えて、ダウンロードが2か月で約50時間になる基準）。
  - 気象庁の震源リストと照合できたものと、列車の揺れとみられるもの（1時間スタック画面の「列車」と同じ解析で、Bamba の時刻表の列車・貨物列車の候補と重なるもの）を除きます。列車の判定は波形を読むので時間がかかりますが、結果を `output/quake_features/loose_trains_v1.json` に保存し、次からは使い回します。
  - 毎日ほぼ同じ時刻の揺れも除きます（時刻が6分以内の候補が、ほかの3日以上にもあるもの。地震は決まった時刻には起きないため。2025/7〜2026/8 では 21:14・21:42・03:40 ごろなどの揺れが繰り返し残り、時刻表に無い列車などとみられます）。期間の中の候補だけで数えるので、短い期間では除かれにくくなります。
  - 残った候補を、最初の候補の5分前から60分ずつにまとめます。60分の中の候補がどれも（前後1分を含めて）`v-net` フォルダの ZIP に網ごとにそろっていれば「取得済み」とします。
- 結果は `batch_plots/quakes` に保存します。
  - `quake_candidates_<開始日>_<終了日>.csv` … 候補の一覧（開始・最大・終了の時刻、長さ、拠点ごとの倍率、波形の解析結果、有珠山の地震らしさ、対応した地震の震央地名・緯度・経度・M・深さ・震央距離・方位・到達見込み・S-P時間）
  - `jma_missed_<開始日>_<終了日>.csv` … 見逃し?の一覧（震央の緯度・経度を含む）
  - `vnet_download_<開始日>_<終了日>.csv` … 外部の観測点で確かめるためにダウンロードする60分の一覧（`--vnet-list` のとき。開始・終了（日本時間）、取得済みか、含む候補）
  - `vnet_check_<開始日>_<終了日>.csv` … 基準をゆるめた候補の一覧（除いた理由（震源リスト・時刻表の列車・貨物列車の候補・毎日同じ時刻の揺れ）と、ダウンロードする60分）
  - `vnet_kbby_<開始日>_<終了日>.html` … 残った候補ごとに、気象庁 V.KBBY の上下動の連続波形画像（防災科研のページ。1時間ごとで1段が1分）へのリンクを並べた一覧。ブラウザで開き、候補の分の段に揺れがあるかを見て、ダウンロードする前にざっと絞り込めます（夜の KBBY はとても静かで、小さな揺れも見えやすい）。同じ URL は2つの CSV の「KBBY の連続波形画像」の列にもあります
  - `vnet_locate_<開始日>_<終了日>.csv` … 残った候補のうち、外部の観測点の波形を `v-net` フォルダに取得済みのもの。メイン画面の「候補の一覧(CSV)を選んで震源を表示」で開き、行をダブルクリックすると、外部の観測点（USUA・KBBY・USOV）を加えた震源推定の画面で、地震かどうかを確かめられます（一覧の表の震源は、到着時刻を保存するまでは満点の4拠点だけで求めたものです）
  - `<開始日時>.png` … 確認用の画像（`--images`。全拠点の上下動に、揺れの区間、自動で検出した P波、P波・S波の到達見込みを重ねたもの）
  - `missed_<発震日時>.png` … 見逃し?の地震の、到達見込みの前後の波形（`--images`）
  - `quakes_<開始日>_<終了日>_<種類>.pdf` … 画像を種類ごとにまとめたPDF（`--images`）。`matched`（照合できたもの）、`usu_high`（有珠山の地震 確定・らしさ 高）、`usu_mid`（らしさ 中）、`missed`（見逃し?）
- `--history` を付けると、候補の期間を履歴に追加し、メイン画面の「過去の実行履歴」から波形を表示できます（タイトルは「地震候補 08/23 22:45:20 浦河沖 M6.0（4拠点 最大×2610）」のような形。同じ期間を自分で表示した履歴があれば、そちらを残します。履歴は1000件まで（以前は50件））。
- 震源リストの地震と対応しても、その地震の見込みの振幅が小さいとき（log A が −1.6 未満、または −1.0 未満で、揺れの始まりが P波の見込みの −10〜+3秒から外れるとき）は「対応?」とします（たまたま時刻が合っただけかもしれないため。KBBY の連続波形画像で確かめた結果から決めた基準です）。
- 10秒ごとの RMS は `output/quake_rms` に日ごとに保存し、2回目からはそれを使います（計算し直すときは `output/quake_rms` を削除します）。全期間（約1年）で、候補の波形の解析を含めて1分ほど、画像も作ると3分ほどです。最初は1日あたり5秒ほどかかります（1時間スタック波形と同じ `output/stack_<日付>_<時>` のSACファイルを使い、無ければ作ります）。`daily_zips` にZIPが無い日は飛ばします。

### 外部ツール（`tools` フォルダ）

WINファイルの処理には、防災科学技術研究所（防災科研）が公開している次の2つのツールが必要です。リポジトリには含まれていない（Git の管理外）ため、各自で用意して `tools` フォルダに置きます。

| ツール | 内容 |
|---|---|
| `win2sac_32` | WINファイルをSACファイルに変換する |
| `wchch_32` | WINファイル内のチャンネル番号を読み替える |

1. 防災科研の「[連続波形ダウンロード](https://www.vnet.bosai.go.jp/)」でユーザ登録を行います。
2. 同サイトからツールのソースコードをダウンロードします。
3. 使う OS でソースコードをビルドし、できた `win2sac_32`・`wchch_32` を `tools` フォルダに置きます（Windows では `win2sac_32.exe`・`wchch_32.exe`）。

- ソースコードには `catwin32`・`wck_32` など他のツールも含まれますが、このアプリで使うのは上の2つだけです。
- OS ごとの注意は [windows.md](windows.md) / [mac.md](mac.md) を参照してください。

## 起動

プロジェクトのフォルダで次のコマンドを実行します（Windows は `python scripts\UsuMantenViewer.py`）。

```bash
python3 scripts/UsuMantenViewer.py
```

| オプション | 内容 |
|---|---|
| `-v` / `--verbose` | 画面のログをコンソールにも表示する |
| `--batch` | 画面を出さずに、1時間スタック波形の画像を一括で保存する |
| `-c` / `--channel` | バッチ処理の対象チャンネル（例: `Hokudai.U`） |
| `-s` / `--start-date`、`-e` / `--end-date` | バッチ処理の対象期間（`YYYYMMDD`） |
| `--quakes` | `--batch` の画像に、地震（震源リストの到達見込み・地震の候補）を重ねる（ファイル名に `_quakes` を付ける） |
| `--trains` | `--batch` の画像に、列車（時刻表と対応した揺れ・貨物列車の候補）を重ねる（Bamba だけ。ファイル名に `_trains` を付ける） |
| `--overwrite` | バッチ処理で、既存の画像を上書きする |
| `--detect-quakes` | 画面を出さずに、地震の候補を探して気象庁の震源リストと照合する（期間は `-s`・`-e`） |
| `--history` | `--detect-quakes` で、候補の期間を履歴に追加する |
| `--images` | `--detect-quakes`・`--locate-quakes` で、候補ごとに確認用の画像を保存する |
| `--vnet-list` | `--detect-quakes` で、外部の観測点で確かめるために v-net からダウンロードする60分の一覧も作る |
| `--locate-quakes CSV` | 画面を出さずに、地震の候補の一覧（CSV）から候補ごとに震源を求める |

例: 2026年8月の地震の候補を探し、履歴への追加と画像の保存も行う

```bash
python3 scripts/UsuMantenViewer.py --detect-quakes -s 20260801 -e 20260831 --history --images
```

## 別のマシンに移すとき

Git で管理していないデータは、`git clone` やアプリのビルドだけでは移りません。次のフォルダ・ファイルを、移す先のプロジェクトのフォルダ（ビルドしたアプリなら、アプリのあるフォルダ）の同じ場所にコピーします。

| 場所 | 中身 | 無いとどうなるか |
|---|---|---|
| `output/picks`（と `picks_` で始まるバックアップ） | 震源推定の画面で手で直した到着時刻 | **作り直せません** |
| `output/history.json` | 実行履歴 | 履歴が空になる |
| `etc/train_timetable.csv` ※ | 洞爺駅の時刻表（JR の時刻表から手で作ったもの） | 列車の重ね表示・照合が使えない |
| `etc/ps_picker_params.json`・`etc/hypocenter_params.json` | 画面の設定 | 既定の設定に戻る |
| `v-net/*.zip` ※ | ほかの機関の観測点の波形（防災科研のページからダウンロードした、防災科研・気象庁のデータ） | もう一度ダウンロードが必要 |
| `output/quake_rms` | 地震の候補の検出に使う揺れの大きさ（RMS） | 作り直すと1日あたり数十秒〜数分。無い日は1時間スタック画面の「地震」で候補の帯が出ない |
| `output/quake_features` | 地震の候補ごとの波形の解析結果 | 次の検出で解析し直す（全期間で1分前後） |
| `jma_hypocenter` | 気象庁の震源リスト | メンテナンス画面で取り直せる（1日あたり2秒以上） |
| `batch_plots/quakes/*.csv` | 地震の候補の一覧・見逃し?の一覧 | 地震の候補を探す処理で作り直せる |
| `daily_zips` | 観測の日ごとの ZIP（とても大きい） | 必要な日を Googleドライブから自動でダウンロードする |
| `service_account` | Googleドライブの鍵 | Googleドライブからダウンロードできない（[windows.md](windows.md) を参照） |

※ **再配布できません。** 時刻表は JR の時刻表から、v-net の ZIP は防災科研・気象庁の観測データから作ったものなので、人に渡したり公開したりしないでください。自分のバックアップや、自分で別のマシンに環境を作るときだけコピーします。

コピーしなくてよいもの: `output` の期間ごと・1時間ごとのフォルダ（WIN・SAC。`daily_zips` から作り直せる）、`output/vnet`（`v-net` の ZIP から作り直せる）、`batch_plots` の画像、ユーザーのキャッシュフォルダ（走時・地図のタイル・フォント一覧。自動で作り直す）。

### まとめて zip にする（`pack_data_mac.sh` / `pack_data_win.bat`）

上の表のうち、`daily_zips`・`service_account` と再配布できないもの（※）以外を、1つの zip（`UsuMantenViewer-data_YYYYMMDD.zip`）にまとめます。アプリ本体のビルドとは別に使います。

- Mac: `./pack_data_mac.sh`
- Windows: `start_env.bat` で環境を有効にしてから `pack_data_win.bat`
- `--private` を付けると、再配布できないもの（時刻表・v-net の ZIP）も入れ、名前を `UsuMantenViewer-data-private_YYYYMMDD.zip` にします。自分のバックアップや、自分で別のマシンに環境を作るとき用で、人には渡しません。
- `--with-zips` を付けると `daily_zips` も入れます（数十 GB になります）。

移す先のプロジェクトのフォルダ（ビルドしたアプリなら、アプリのあるフォルダ）で展開します。同じ名前のファイルは上書きされるので、移す先で手で直した到着時刻などがあるときは、先にバックアップしてください。`service_account` は人に渡る zip に入れないよう、別に移します。

## 今後の予定（TODO）

`scripts/UsuMantenViewer.py` の先頭に一覧があります。主な未対応の項目:

- WINファイル・SACファイルのキャッシュ処理の最適化
- 変更しないファイル（`tools`・`service_account`・`etc` の設定ファイル）はアプリと一緒に置き、ユーザーの操作で作られる・変わるファイル（`output`・`daily_zips`・`batch_plots`・`etc/ps_picker_params.json`・`etc/hypocenter_params.json`）はユーザープロファイル配下に置く
- 外部ツール（`win2sac_32`・`wchch_32`）のビルド方法の記載（Mac は gcc（Xcode のコマンドラインツール）、Windows は MinGW の gcc で、それぞれの Makefile を使ってビルドする。どちらもそのままではビルドできないため、当てているパッチをリポジトリに追加する）
- 震源推定の画面の使い方のドキュメント（とくに遠い地震: 表示の範囲を合わせて S波を手で指定する手順、距離による大森係数 k の目安。S-P時間から走時表で距離を求める方法も検討）
- 地震の候補の震源（`--locate-quakes`）で「近い地震」と判定する基準を厳しくする（到着時刻が少ないと、残差が小さくても位置が当てにならないため、「到着時刻が6つ以上」のような条件を足す）
- 波形表示（全拠点）の画面で、表示する時間の範囲を1分単位で微調整できるようにする（基本は終わりの時刻を動かす。S-P時間の試算で前に入った大きな雑音を外したいときのため、始まりの時刻も動かせるようにする）
- 洞爺駅の時刻表（`etc/train_timetable.csv`）の各行に、有効期間（開始日・終了日）を持たせる（ダイヤ改正の前後で正しい時刻と照合するため。入力用のテンプレートと、時刻表を読む処理も合わせる）

## 謝辞

- 観測には、京都大学防災研究所附属 地震災害研究センターからお借りした満点地震計を使用しています。
- WINファイルの処理には、国立研究開発法人 防災科学技術研究所が「[連続波形ダウンロード](https://www.vnet.bosai.go.jp/)」で公開しているプログラム（`win2sac_32`・`wchch_32`）を利用させていただいています。
- 震源推定の配置図の背景には、国土地理院の[地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)を利用しています。
- 地震の照合には、気象庁の[震源リスト](https://www.data.jma.go.jp/eqev/data/daily_map/index.html)（暫定値）を利用しています。
